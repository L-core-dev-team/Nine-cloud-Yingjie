## 五、要做出的产品体验

映界是《九霄》的视觉游玩模式。玩家仍通过文字行动、阅读剧情；图片表现当前能看到的世界，并保留行动造成的变化。

核心例子：玩家第一次进入酒馆，画面中有几个人。之后玩家救回其他人，剧情确认他们来到酒馆；玩家再回来，仍能认出同一间酒馆，同时看见人员和状态的变化。它应当让人感觉自己创造了一个值得探索、持续存在的世界。

### 必须保留的产品原则

1. 初代固定修仙，以已有世界书为基础；未规定的部分允许由剧情创造，新事实在当前存档中延续。
2. 剧情事实与玩家可知范围优先。图片中的偶然人物、门窗和道具不能反向成为权威剧情事实。
3. 进入区域是主要出图时机；区域内重要变化同样需要响应。普通对话可以复用现图。
4. 高潮和大场面由 AI 结合剧情判断；价值低的段落可以复用或跳过。
5. 同一地点应合理连续，允许改变视角；视野可以是一个村庄，也可以是飞行时的一片山脉。
6. 预设图、世界书重点地点图、旧图复用和动态生成可以混合使用。
7. 已发现明显矛盾的图片不强行展示；不确定时保守处理，并提供简单纠错与重新生成。
8. 玩家可以关闭生图；等待、失败、拒绝和无图片服务不阻塞仍可继续的文字玩法。
9. 图片需要与剧情、地点和存档关联；基本历史、复访连续性和手机/电脑体验属于首版工作。
10. 玩家可设定初始外观，重要人物形象逐步固定；具体界面深度仍按阶段验证。
11. 玩家使用自己的第三方 API，平台不承担玩家的生成费用；费用产品化与密钥保存细节仍后置。
12. 内容遵循平台规则；万卡阁继续隔离。

“宁可不出错图”是产品取舍原则，不能被写成模型已保证零错误。实际工程要记录已发现的错图、漏判、处理方式和未覆盖场景。

### 代表性场景

| 场景 | 应体现的行为 |
| --- | --- |
| 酒馆内普通交谈 | 剧情可以推进，画面仍适用时不必每轮重画 |
| 谈起远处山峰、回忆旧事 | 不把谈论、回忆或计划误判成角色已经移动 |
| 救人后返回酒馆 | 同一地点身份保持，已确认到场的人物变化进入新画面 |
| 区域内出现重要变化 | 无需先切换区域才能更新画面 |
| 飞行或俯瞰 | 允许扩大视野；不假定所有场景图片具有统一地图比例 |
| 渡劫、战斗或剧情高潮 | 表现已发生且玩家可知的内容，不提前画出胜负或秘密 |
| 生成失败、关闭或迟到 | 文字继续；图片只进入其仍适用的当前视窗或对应历史位置 |

**建立或打开会话 → 玩家行动 → 获得并保存文字结果 → 关闭或刷新 → 重新打开 → 继续行动。**

## 十一、实现中必须检查的行为

以下是工程验证案例，不是替用户提前冻结正式产品验收数值。

| 案例 | 要验证的问题 |
| --- | --- |
| 普通对话与重复描述 | 不因每一轮文字或地点别名变化就重新造一个世界 |
| 回忆、传闻、未来计划 | 不把未发生的内容写入当前可见状态 |
| 同地复访与人员变化 | 原地点可识别，已确认到场/离开的人员变化持续保存 |
| 视野改变 | 当前视野与剧情相符，不丢失地点关系 |
| 图像中的偶然新增内容 | 不自动回写世界书或权威剧情 |
| 旧图仍然适用 | 回合继续后仍可复用，不机械按最新回合号判废 |
| 旧图已矛盾 | 隐藏或替换，不能为了有图而继续误导 |
| 图片迟到与乱序 | 核对用户、会话、已有分支、地点和视觉状态；不覆盖不适用的当前视窗 |
| 重开、切会话、关闭或删除 | 旧请求回包不恢复已关闭或已删除的当前展示 |
| 超时与结果未知 | 有请求标识和查询路径；不无依据重复生成 |
| 模型拒绝或服务失败 | 合规文字仍能继续；记录可理解的状态 |
| 手机与电脑 | 图片、文字、等待、失败与历史都可操作 |
| 历史与纠错 | 图片关联正确剧情，纠错和重画不篡改既有剧情事实 |

自动结构校验、规则检查、模型语义判断与人工观察各有覆盖范围，记录实际用了哪一种。测试应针对真实风险和重要状态转换；不为文案或无行为变化的改动堆积测试，不以用例数量代替可用性证据。

## 十二、执行边界和遇到缺口的处理

- 保留用户现有工作区与未提交改动。不要直接改写九霄main，不自动合并现有会话、存档或数据库。
- 复用上游已有能力；如果需要接入修改，明确触及的文件、作用和回退方法，使用隔离任务分支。
- 使用实际已有、仍有效的访问与调用权限。旧联测的限时授权不能自动延续；新付费调用、生产部署、公开发布和扩大账号权限不能由建仓指示推导出来。
- 用户已经后置的四类问题不作为重开访谈的理由。暂时缺真实调用条件时，继续完成源码核查、合成样例和可验证的本地工作，准确标明未覆盖部分。
- 真正必须由用户补充的条件，只报告最小缺口、影响范围和已完成的其他工作。不要把一个局部缺口扩大成整个项目完全无法推进。
- 不提交密钥、真实环境文件、私人数据库或未获准再分发的素材。当前没有选定开源许可证，不自行增加许可承诺。
- 功能、模型、规格与排期出现变动时，更新对应决定的来源和状态。不能把“助手建议”改写成“用户确认”。
