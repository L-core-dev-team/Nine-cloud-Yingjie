## 2. Gate A｜冻结一条 14 回合自然修仙剧情

只编写一条完整、有前后因果的合成短篇连续剧情，约 2–3 个明确地点、3–5 名稳定人物，14 个依次保存的修订。以自然小说表达，不全用机器模板句。不需要生成真正游戏文字，不额外请求模型写剧情。先由实验设计者编写正文并标注金标；冻结正文、行动标签、独立逐回合/字段/事件金标、提示与协议、最小安全验收和评分器。金标用于评价，不进入候选请求或运行时状态。若同一作者标注，明确没有独立人工盲评。

必须覆盖但不指定逐轮答案：
- 有完整当前观察基线（地点、人物、视角、至少几种物件状态等）；普通交谈、无可见变化的回合，不能靠每次重述全量字段来制造容易通过。
- 同一场景人物离开和另一名实际到场；同一物件可见状态改变、遮挡/不明、重新观察；区分完整名单、部分已见、未知人数、确知无人。
- 离开地点到另一地点，隔至少两个修订后复访，必须重新判断当前可见事实；同名物件/相似地点不得串身份。不同地点的旧事实不自动迁入，先前在场者不能凭旧记录直接画回去。显式延续或重新观察才支持恢复。
- 至少一个夹有回忆、转述、梦境或假设的混合回合，后续现实有明确变化；过去事实不得变成现在。
- 一次有歧义/缺证导致局部不就绪，后来由当前证据恢复；至少一次首次得知旧事实或更正旧候选，不能误记为真实新变化，也不能倒写旧时点。
- 具有前面铺垫和后来真实兑现的安静高潮，以及另一处明显有视觉表现价值的关键事件；另含普通但有微小视觉改变、重要但不可见/信息不全、计划未兑现、无变化谈话。不能把“打斗”“离开”“高潮”等词本身作为标签。高潮金标、视觉变化、画面可表达性、是否建议更新分开。

本轮按 14 个自然剧情修订冻结，不再增加新故事或扩大语料。旧 A/B/C/D 和前序失败为公开回归，不计新盲测。用户没有要求在本轮训练模型或生成真实图。

## 3. Gate B｜实际 14 份首答，稳定状态链

在独立目录（建议 `packages/ai-snapshot-pilot/stability/`）建立通用于本条固定故事的最小可重放入口：
- 使用宿主创建的研究会话标识、稳定地点/人物/物件身份与修订，不能把模型输出的地点字符串直接当全球身份。按序处理 1…14；前缀只能截至当轮。给每次独立 Codex 对话统一的冻结提示、schema、当轮正文、必要的同组前文/可追溯已知候选及真实上一投影；明确先前值不是权威，哪些是未知、已被拒、仅历史或待审核。不得给金标、未来信息或其他会话。每回合一次首答，先原样归档再处理；不改原答，不重抽。若环境不可用报 NOT_RUN。
- 区分「历史曾确认」「当前可见」「场景身份记忆」「当前可否继承」。离场、遮挡、不同地点、失去证据时隐藏或标未知；不能因一次字段失败全局丢弃其他有独立有效证据的字段。完整重新观察允许从未知/隐藏恢复；无依据时不凭沉默继承。若完全不影响某物件且有具体同场景延续证据，可保留当前状态；没有延续或当前证据时保留最后已知的历史状态、当前状态 unknown，而非假定仍然相同。状态稳定不意味着旧值永不失效。
- 继续区分物件 ID、属性/可见状态、首次获知、重新观察/纠正、真实变化候选与视觉摘要变化。场景身份连续≠现场内容连续；画面一致才可提出复用。
- 重要支持/限制/排除证据分开，校验同一 scope、修订、真实唯一引文及冲突。不因模型给 current/visible 标签或找到子串即宣称语义得到独立证明。保留 `AI_SCENE_PROPOSAL / RESEARCH_ONLY`。原正式 `sceneEligible=false / send=false`。
- 在预先冻结的四个高风险节点做最多 4 份独立覆盖/矛盾审核（不是生成模型自审），至少覆盖跨地点复访、物件状态、混合过去/当下与重要兑现证据。审核者看完整当前正文、必要前缀和实际候选，不看金标/预期错误。审核意见、确切引文和原始首答分别记录；缺审核、漏项、冲突、语义不确定均保持待审，不能借审核直接修改原始答案、补金标或承诺权威。其余帧标明未独立覆盖审核。
- 只用本地脱敏 JSON/SQLite 等最小隔离存储保存输入/候选/首次获知与事件；无需改 PG 或新服务器。执行连续运行与中途关闭/重开（例如在第 7 修订持久保存再恢复），原始答复不得重复调用模型。恢复后投影、当前状态和历史摘要与同一输入连续运行一致；重复同修订不新增事件，冲突同键、乱序缺口、跨 scope、未来证据被阻断。逐前缀回看当时已知与当前结论分离；后获证据不能改写早期的已知画面。

## 4. Gate C｜实际输出和节奏基线（不出图）

逐轮输出可读场景描述：当前地点、观察位置/朝向、可见名单与人数（未知和 0 不混淆）、重要物件及状态、环境、相对前帧的实际变化/新获证/未知、回忆等排除项、审核状态。记录旧场景是否可用以及为何不可继承。报告必须展示实际输出，不只是分数。

对照冻结金标，单列正确、正确未知、漏识别、错误/无据采纳、状态漂移、跨地点污染、重复/回退污染、恢复成功率、相邻稳定摘要；语义等价评阅与字面原分分开，不以全拒绝拿 PASS。特别保留第一处红灯。若同一剧情的前后输出不一致，找出最小问题；允许小范围通用修复机械层并重放同一归档首答，禁止重抽/改题/按样本硬编码；模型原始语义错误仍记录。

**节奏只建立基线：** 同一 14 回合分别记录：
1. 剧情重要性：普通、铺垫、待兑现、重要转折/已兑现、未知；引用前因及当轮结果，不把未来或未发生计划当现实。
2. 可见状态变化：地点/人物/物件/机位等差异，区分新的知识/纠正与实际事件。
3. 可表达性/展示条件：信息充足、部分未知、冲突/待审、关图/权限不足。
4. 研究性更新建议：new / edit / reuse / defer / text-only（允许 unknown/needs-review）；普通小变化不必立即请求新图，若旧图已不符合当前不能伪装继续展示。无变化的重要剧情也可仅文字或复用；高潮不自动跳过证据门禁。
使用现有 `visible-change/1`、H2/H3 的已支持入口做公开对照（确有匹配输入时才调用；原 S2 资格不足则记录不适用，不伪造 S2 Visual/许可）。另列同一新链路的人工金标基线，比较「每次可见变化」与「按叙事重要性及可表达性选择」的差别。**本轮不实现新的高潮导演模型、不调权重、不引入实际模型时机额外调用**，只有候选/研究建议，真实和模拟图片 dispatch=0、正式 send=false。若语义稳定性不合格，先报告，时机基线不宣称已验收。后续单独批准时机优化专项。

## 5. Gate D｜有限验收与停止

- 14 回合真实首答逐个计数，至少能完成跨地点后有根据地恢复、人物离开/到场、物件状态变化、回忆不污染以及缺证后重新观察正例；不能全部隐藏或手工补答。完整模型审核与人工复核范围如实标注。零跨 scope、未来泄露、梦境/转述冒充当前、错误人数、无据继承、回忆复活人物、遗漏却标为已充分审核、假已发送。存在重大错误则 FAIL；安全但部分识别/稳定/恢复不足为 PARTIAL；满足冻结的有限研究验收才能标 `STABILITY_DIALOGUE_PILOT_PASS`。不承诺无限长度、全部自由叙事或生产安全。
- 逐节点对比连续/中断恢复/历史回看，并测重复、拒绝、隔离。复跑 02R 相关的 7 组修复、旧 14 项恢复、原 A 和旧 B/D 回归、触发 4 项；保持旧证据，H2R/H3B2/H3B2S FAIL 不抹平、B2 生命周期依赖不扩改、Luna LIVE_BLOCKED 和 I2 LIVE_BLOCKED_COST_BOUND 保留。不要求复跑全部旧 1,765 前缀。
