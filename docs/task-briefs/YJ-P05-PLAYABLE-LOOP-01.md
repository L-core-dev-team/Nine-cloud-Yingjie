## 2. A｜固定一条原生短局，先把真实来源接通

### 2.1 静态核查所得的候选路线

无 AI 路线预演使用单独标记的测试存档；正式试玩从新建存档开始，由页面实际提交八回合。预演记录不计入正式体验与模型槽，不回填成正式页面行动的证据。

### 2.2 规则结算与正文保存

沿用 ServerTurnService 和原生认证/存档服务。固定版本的构造器可在 narrator 缺省时使用 deterministicNarrative；本轮装配 core.runtime.narrativeFallback 并请求正文，不传模型 narrator，不配置模型 role/provider。例如该版本的参数顺序为 repository、rules、narrator、timeout、deterministicNarrative；实现时以源码为准。

原 B2 宿主 execute(..., false) 不请求正文；不能直接沿用后又宣称已有完整阅读过程。原服务的 recordNarrativeStatus 保存状态，不等于保存了正文全文。P05 侧车必须持久化实际返回的正文及 source=deterministic，并绑定 owner/save/branch、requestKey、resultingRevision、原回执摘要及规则/内容版本。先保存来源，再创建模型题包。

一次行动的规则结算只执行一次。同键重复只读取已保存结果；同键不同内容拒绝。如果规则已经提交而正文侧车尚未写入，恢复时从已授权读取的原回执和固定 fallback 重建同一确定性正文，标记恢复来源；无法取得原回执则显示正文待恢复，不能重演行动或另造剧情。不要重入 execute 来再次扣除资源或发放奖励。

当前地点、子区域、任务和可行动作取自原生允许展示的认证结果。确定性正文属于表现层：例如父地点名不能单独补齐观察位置、朝向或人物总数；领奖和解锁也不能推出“某人递符、抬手、落笔”等未写出的动作。模型只接收玩家可知内容与必要公开规则后果，不导出整个内部状态或隐藏设定。

## 3. B｜为新回合增加显式运行时输入

### 3.1 每轮输入与存档

建立独立的运行时入口，接收真实短局记录。不得覆盖旧 STORY、改旧 scope、将新剧情伪装成 old/new，或读旧修复标注替新答案放行。

每轮至少绑定：

- 归属：本地受控用户、save/session、branch、revision、行动请求键。
- 来源：本轮已保存正文、截至当前的必要前缀、正文摘要、已授权的公开规则后果及来源类型。
- 延续：上一实际保存的场景投影、未知项、历史最后观测，以及上一实际时机结果；包括无效、缺失或待处理状态。
- 处理：输入格式与提示版本、题包/原答摘要、处理结果与理由、派发状态。

新记录不能读取未来回合、验收路线的预期结果、作者金标、旧诊断或审核意见。保留可追溯的原答字节；程序接受、执行者修订和人工评阅分别记录。

### 3.2 来源标注由本轮状态候选提供

状态首答须把主张拆到对象与属性，至少包含候选值、观测状态、当前原文短引，以及对应的限制目标、未知项、非当前层和事件候选。允许同一句分别支持“近处可见”和“深处未知”。

缺少当前证据的 unknown 可没有引文，只记录其目标和缺证状态；明确遮挡、非当前层及正向叙述主张分别引用对应正文。原生公开规则值使用受权字段或事件来源，不强行配一段并不支持它的叙述引文。

宿主负责定位引文、校验归属/修订、分配稳定 claimId，并保存实际投影。模型主张保持 origin=model-candidate；对照原生公开规则有冲突时保留原生值并将候选标为冲突，不能用候选覆盖权威存档。

无原文支持、目标不明或同属性相互冲突，保留未知/待审。没有当前证据时，不把历史最后所见当成当前已知；未知、部分可见、明确无人必须分开。属性分别延续，历史观察、首次获知、现实变化和明确后果分别登记；不靠增补听泉堂/伏潮井专用正则完成新短局。

这套结构不证明一般语义正确：对象划分、叙述层级和引文含义仍可能由模型判断错误。执行者逐轮对照实际正文记录首个问题，不把 hash、结构检查或零派发当作语义全通过。

### 3.3 时机只消费程序实际保存的投影

状态首答处理完后，再生成时机题包。焦点引用实际投影中的 claimId 及当前短引；保留限制目标、未知项、差异、叙事事件和上一真实建议。状态首答无效时，传递这一结果及可靠来源，不能由执行者补写“正确答案”再交给时机模型。

新时机接线不读取旧 annotations.json，不允许执行者看完时机答案后追加 alignment 使其通过。检查来源与指向，无法支持的焦点拒绝或待审；不得将这种有限检查宣传成通用语义确证。

通用提示延续 TIMING-01R 的澄清：安静重要后果可由文字表达；首次建立空间和局部可见可以有画面价值，但是否值得更新仍由当轮信息与阅读节奏决定；被阻断的上一建议不自动要求补偿性出图。直接 reuse 与需裁切/处理分别表述；没有参考图就保持条件建议。理由不得加强成未经原文支持的目击者身份或精确同步。

## 4. C｜把研究中继放进可体验的页面

### 模型调用方式与上限

本轮固定为 CODEX_RELAY：程序导出只读题包，执行者使用现有 Codex 独立对话取得首答，再原样导入程序。每轮状态与时机各一次，最多 16 次；新增补答、重抽、独立审核和剧情生成均为 0。首答格式错误、失败或送达未知也占该槽，保留原结果，不换模型凑通过。

首发前提交通用提示、运行时格式、路线及验收要点，记录实际完成顺序和内容哈希即可；本轮不重开冻结时钟取证专项。模型只接收到该槽题包，使用独立上下文，不继承执行任务书、验收预期或后续剧情。记录实际投递/返回及摘要；若工具无法提供强隔离，报告观察到的访问范围，不声称 OS 级隔离。

页面如实显示“分析待回传”等状态。中继属于本地研究操作，不等于游戏自主调用模型。准备、校验、导入和展示应由程序完成，执行者不逐轮改 JSON 填答案。现有订阅中继不可用时，完成可做的工程部分，新 AI 接入记 NOT_RUN/PARTIAL；不改用付费 API、旧首答或硬编码推荐冒充。

### 玩家页面

主界面提供当前地点、已保存正文、可行动作、历史回看和继续入口。技术字段、完整引用与校验理由放在折叠诊断区；时机建议可用一句可读说明展示。明确本轮没有实际剧情图片，不能把示意占位称为生成资产，也不能记录不存在的“已展示画面”。

行动成功以规则存档为准。场景/时机待处理、无效或缺失时，文字玩法仍可继续。正常验收按轮完成桥接；另用一个已准备题包验证“分析待处理时仍能行动”，不额外增加模型槽。

后台结果必须绑定原回合：晚到答案可补入原回合历史，不能覆盖更晚的当前状态。后继题包保存其实际形成时看到的前序版本；晚到结果不自动重建题包、不重抽后继模型、不假称后继曾看到新信息。

界面从真实当前存档生成动作；至少一项行动改变后续可行动作或持久状态，例如领取奖励后领奖入口消失、后续路线解锁。不能用只读 trace 翻页替代这项验收。

## 5. D｜持久化与退出后继续

旧 B2 启动脚本会新建空库并清理目录，createTestGames 重新创建账户和 secret；这些是测试设施，不具备现成的同局 resume。P05 需要本轮专用的 start/resume/stop/cleanup 操作：

- 首次启动创建隔离资源；重启读取同一专用目录和原生存档，不能静默新建一局冒充恢复。
- 账户、连接信息和必要本地 secret 仅放受限本机配置，不写 GitHub；沿用既有认证机制，重开后重新鉴权。
- 持久化已提交正文、候选、时机、来源绑定和处理阶段；先保存题包与派发占位再发，导入后保存原答及结果。收到结果后重开不重新派发；送达未知不自动重试。
- P05 当前态重新读取认证 PG 快照，并核对本地记录归属、修订与回执。旧 B2 的内存 checkpoint/ledger/refs 不能凭序列化标记自动变成恢复后的可信证明。若未实现相应历史证明恢复，明确保留历史未获证；本轮不扩成一般历史读证平台。
- 已接受行动与派生分析分层保存，不跨系统声称已有原子事务。中间阶段失败可恢复；无法恢复的派生内容保持待处理，已提交游戏状态不回滚。
- 关闭页面、停止宿主或结束测试进程不自动删试玩存档。交付可恢复的本机启动说明；cleanup 只清本轮标记资源，不影响其他项目或既有数据库。

主路线在 R4 完成并保存后停止宿主进程，重新启动同一局后从 R5 继续。确认奖励未重复发放、当前地点/子区域/修订一致、已保存正文可读、候选与时机原答不重抽。另在一个尚未派发的题包待处理阶段重开，确认继续工作而非重复占槽；可使用主路线同一轮，不扩成长故事。

## 6. 有限验收与状态口径

只做能够解决本轮实际风险的验证，不重跑全部 H3 前缀或 B2 42 项。原实验代码未改时，旧通过回执保持历史记录；共享代码确有变化时，只补受影响入口的兼容检查。

| 维度 | 必须看见的证据 |
|---|---|
| 行动与正文 | 从实际页面提交短局动作；规则存档/修订/回执与保存正文对应，正文标 deterministic |
| 行动后果 | 清障的实际可见结果、领奖的实际权益/解锁后果、普通交谈分别展示；说明哪一步改变后续选择 |
| AI 新输入 | 新回合导出题包 → 两类首答 → 实际处理投影 → 页面，原答与调用槽可追溯，无旧标注/金标放行 |
| 未知与复访 | 当前与历史分开，复访不串地点；缺证字段不补满，限制按对象/属性保留 |
| 恢复与幂等 | R4 后宿主进程停止并恢复同一局；已完成槽不重发；同键重复不增回合，同键异内容与过期修订拒绝 |
| 范围与迟到 | 一个跨会话/未来引用或伪造 claim 引用反例；晚到结果不覆盖当前；登出后的请求不可继续读取 |
