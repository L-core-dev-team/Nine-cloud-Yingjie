## 1. 目标与最小实验

上一项在自然合句、离场和回忆后的当前叙事上全部拒判，说明固定正则提取不能成为自由叙事核心。改为「语言模型提出语义候选 → 程序验证来源/结构/时间/连续性 → 独立金标评价及人审」。本轮只检验是否能提取足以表达一帧场景的文字；不把模型输出变成可信世界权威、不解决所有语义情况、不生成图片。

- A 组：完全复用 `packages/first-play/test/scene-snapshot/input.json` 的原始三轮及独立 `gold.json`（听雨酒馆：三人 → 苏禾离开，两人 → 回忆三人，当前仍两人）。不改题，不替换为旧正则支持句式。A 属于已知公开基准，不计为新盲测。
- B、C 组：各一条全新的三轮合成自然剧情，和 A 的地名/人物/布景/措辞不同。至少一组保留人物/背景并只改变一个可见元素，另一组含具有歧义的回忆、梦境或转述与真实当下交错；确保有明确可确认的正例，至少一个关键字段确实未知，且有不能当作现时事实的干扰信息。禁止仅通过同义词替换或把所有信息全重复制造容易满分的测试。
- 先冻结 B/C 原文、独立逐帧人工金标、评分器、固定提示、模型及输出预算；A 原数据保持逐字一致。三组分开会话和状态，无交叉借用。模型输入不含 gold、预期人数/变更答案、未来轮、其他组历史。评估者独立于运行；若同一作者构造，明确非独立人工盲评，不夸大。
- 按 A→B→C 顺序，每组 R1→R2→R3 单次请求一轮。只给当前冻结正文、此前同组已提交正文的必要前缀、必要的上轮候选状态（显式不可信），以及统一提示/输出结构；不得给出未来或用 gold 补状态。固定版本一次跑完，不在看见结果后调提示、换模型、补第二次推理。若发送被拒或状态不明，保留首个结果，按门禁停止；可少于 9 次，不追求耗完额度。

## 3. Gate B｜候选协议与状态

建议独立 `packages/ai-snapshot-pilot/`（目录按需），复用已有 schema/状态思想、明确不同来源。不要给 card-history/原生 RULES 安全认证偷换意义，不把 AI 的自报置信度、schema 通过或引用哈希当事实确证。

每轮模型只返回一个严格、有限的 JSON 对象，包含：
- 场景候选：地点/场景身份、玩家观察位置、朝向、人物集合（稳定人物身份、名字、在场/离场/未确认、名单是否完整），设施与可见结构、时段、光照。
- 变更候选：按当前轮明确证据列出 add/remove/keep/unknown 等最小变更。不能靠补全故事脑补身份或状态；只有确切完整基线 + 明确延续/变更依据才继承。未知 null、未确认名单与已确认空集合不同。人数由完整名单机械计算，不从模型随意填；未知不可填 0。
- 每条候选的来源引用：修订、原文准确短引句/范围（UTF-16 起止可由程序对原文精确定位，不能自报偏移就通过）、叙述层 current/past/dream/hypothetical/reported/unknown、玩家可见性、继承来源。复合句和回忆后的现实分别表达；不能从过去三人谈话推出苏禾回来了。未说明外观、年龄、服装、家具数量/精确布局等保留 unknown。
- 输出标签明确为 `AI_SCENE_PROPOSAL / RESEARCH_ONLY`。程序只能验证字段类型、引用是否实际出现、所属同组前缀、来源/时间/版本及冲突/完整性等机械事实；**机械通过不证明引用蕴含候选，也不证明模型对现实/梦境归属正确。** 未获独立审查前不得发布为可信世界事实。
- 用程序构造隔离的**候选**场景状态与视觉差量（可在本地候选模拟账本中演算）；R2 移除指定角色，保留明确不变字段；R3 没有实际变化则候选视觉版本/摘要保持等价。拒绝整个场景与保留局部未知分别统计，避免借旧图或旧场景假装当前。保持既有权威准入、角色卡缺口与正式 Visual/图片门禁不变。任何真实或模拟 generate/edit/dispatch 均为 0；所有实验候选 `send:false`、正式 `sceneEligible:false`。单列“文本候选完整度”，不与正式图像资格混同。
