## 3. 制作真实图片，次数与原件留证

正式调用前保存三份简报、对应正文/原候选摘要、允许的非正典选择、图片适用条件与本节调用账本。每份简报只用该节点及必要的先前材料，不能把后续发现提前画进开场。冻结是为追溯制作依据，不重开时钟专项或新盲测。

### 3.1 三个主槽与一次修正

- I01、I02、I03 各最多一次真实图像工具尝试，一次目标一张。使用当前已有订阅的官方工具，不填写项目 Key，不转付费 API。调用前先占用该槽；失败和送达未知都计入次数。
- I01 生成后先看真实原件。I02 若引用 I01，须记录实际参考原件、摘要、用途和当前构图适用性。R2 已到作业位，不能仅凭同父地点就要求 I02 保留原机位；引用可以只服务画风/已审表现，不能把首图自创布局变成剧情事实。没有合格参考可在 I02 主槽内按当前简报新生成，并如实注明。
- 三个主槽之外，全局最多一次定向修正，只用于已明确返回且发现具体内容错误的图，或已明确未送达/失败的技术问题。先写明错误、实际结果状态和修正范围，保留首次结果。送达未知不得重发；不为画风偏好反复抽图。一次修正仍失败或预算用尽，就报告未完成。
- 独立文字研究对话、补答、模型审核仍为 0；执行者目视审阅属于本轮制作工作，不伪装成新独立审核。模型 ID、服务请求 ID、配额或费用未披露时记未知。
- 工具不可用或要求独立付费时，停止相关图片调用，完成可做的本地工程并如实标记 BLOCKED/PARTIAL；不把占位图、手画示意、旧酒馆图或其他故事素材算作本轮实际图像。

### 3.2 原件与接受资格

保留实际工具输入、结果或失败、时间、尝试号、参考与输出文件摘要、实际尺寸，以及执行者逐图目视意见。先审是否确实表达了本文依据、是否画出了未知人物/物体、是否把声音画成实体、三图是否适合连读。具体列出看到的偏差；文件存在与 hash 一致不等于画面内容通过。

仅接受的原件进入试玩素材清单。非敏感合成原件允许保存在本任务私有仓库资产目录；原件不覆盖，必要的网页缩略图另存并绑定原件，清楚区分生成、缩放和直接复用。校验实际文件格式，不能把非 PNG 改扩展名冒充 PNG；如需合法格式转换，另记派生关系并保留原件。交付完整本机可读文件，不能只留下临时 URL。图片若需改内容，使用获准图像工具并占调用次数；不要程序涂改后当作工具原始输出。

## 4. 运行时适配与显示记录

### 4.1 预置资产和存档实例分开

三张图登记为本任务、固定原生内容版本的合成预置素材，有独立资产 ID、文件摘要、制作来源、使用范围与适用条件。它们可在本轮专用验收档和道主的独立本机图文试玩档使用，不依赖旧 demo 的 owner/save/requestKey。

每一次当前或历史展示另绑定该局已认证 owner/save/branch、真实 revision、正文与回执、地点/子区域、视野依据、资产版本、匹配原因和展示状态。不得复制旧 demo 的归属标记，或将“已审素材可用”偷换成“新存档已完成状态/时机模型分析”。私人图片、其他用户/项目资产与未知来源文件不在本轮可用集合。

资产匹配可以限定这条已知路线和固定内容版本，明确写为有限预置适配器。正文摘要可用来核对素材适用的来源，但不能仅凭摘要、回合号、相同地点名就获得资格；还须检查该局真实来源绑定和图中全部承载剧情的条件。条件缺失、冲突、版本变化或路线外的行动一律回到文字。

### 4.2 原建议、运行时决定与真实显示分开

旧十六份首答只作制作参考和既有研究证据，不导入新存档充当本轮模型输出。本轮不重跑它们，也不把新的显示记录拿去改写当时模型看到的“无参考图”或旧评分。

新适配层分别记录：引用的原建议来源（如有）、人工确定的素材条件、当前真实匹配结果，以及实际显示/收起/历史保留/复用/失败。玩家页可以简洁呈现，完整技术理由放折叠诊断区。R8 只有本局真实显示过 I03，才可记录本局此前实际显示过该图；浏览器实际解码并显示后才登记展示，宿主发出一个 URL 不等于实际渲染。若用户此前关图，R8 满足条件仍可首次显示该素材，但不标成本局再次展示。刷新、轮询和历史回看不重复生成图片或冒充新回合展示。

沿用“图片不一定每轮失效”的规则：若同地点、同视野适用范围与持久条件仍成立，文字行动不必机械撤图；同时标清“上次所见”，不能说每轮重新确证。离开地点、进入不相容子区域、缺证复访或遇到反证时重新评估。迟到结果只能在重新核验适用性后用于当前，或归入原回合历史，不能覆盖不相容的新场景。

### 4.3 不开后台图片 API

本轮工具调用发生在素材准备阶段，游戏启动、行动、刷新和重启均只读已审本地素材。单独记录工具制作次数与运行时图片 API 派发数，不把三张真实图片记成“图片工具 0”。

原生权威状态、CODEX_RELAY 研究槽、预置资产与显示日志分层保存。旧 blocked 常量和 I2 的 allowLiveSend 等门禁保持原语义，本轮不通过接入旧派发队列获得隐式发送权限。只复用合适的纯函数和文件检查；无需迁移整套 WorldAssets、通用图像任务或旧历史平台。

图片读取维持现有本机鉴权及同源约束，服务器只按已为当前会话建立合法展示绑定的资产 ID 返回受限目录中的图片字节，不接收任意文件路径或外网 URL。预置素材已在磁盘上不等于玩家已发现：正常页面及素材接口不能在 R1 提前暴露未来的 I02/I03，也不能从未到达的历史回合读取；验收回看仅提供该档实际发生过的记录。图片缺失、损坏、加载失败或用户关图时，行动与正文照常可用。
