# YJ-08 首段游玩联调接续任务书

从 YJ-07 实际最新交接提交建立独立接续分支。目标是在普通角色卡中把已保存文字接到可审查的画面选择，分别取得本地模拟与获准供应商的回执。

## 已验证的起点

- YJ-04 的 syncCardHistory 可读取本地九霄普通会话已完成历史并保存稳定地点。固定正文/标注可产生 ready、not-ready 和连续视觉版本。
- YJ-05 的 PostgreSQL 任务、审阅、原件和不确定发送恢复已有回归。YJ-06 的真实角色卡页面已通过九步模拟流程。
- YJ-07 的 WorldAssets 可在受信上下文中核对会话世界书、地点和当前文件并返回匹配或原因。三类来源与预设显示经过合成授权资料、本地数据库、鉴权 HTTP 和 Chrome。详细命令见 [07 报告](../reports/YJ-07-worldbook-assets-report.md)。

## 可立即执行的本地子项

1. 在同一回环宿主扩展适配器，以 YJ-04 已完成的 card-history source 和原文作为输入，保存提取方法、依据与版本。先选择一组获准脱敏正文，由人工给出期望观察，再比较逐条提取结果。未确定的地点和未揭示人物须保留未就绪。避免仅凭玩家行动或世界书记载添加眼前事实。
2. 接入一条受信的画面选择流程。对当前场景优先检查符合许可的预设或可复用的 05 资产；记录匹配理由、无匹配原因和当前开关。需要编辑时交由 0.1.1 参考资格检查，不把预设句柄当成已生成资产的 attemptId。没有可用原件且关图时继续文字。
3. 用确定性本地适配器驱动单一真实页面，再验进店、交谈、五人、离开/复访、点灯、关闭、失败、刷新、切会话。增加新书替换、撤权、损坏和旧结果迟到。分别对账正文修订、地点与视觉版本、预设句柄或任务/尝试、实际发送次数。每次用干净测试库，按来源区分固定脚本与额外标注正文。
4. 交付单独的本地联调报告、回归命令、脱敏回执及未覆盖项。预设优先的自动决策、额外正文的提取和第 3 步的组合验证均属 08 待实施工作。

## 需要外部条件的验证

真实文字模型或独立图片适配器、供应商鉴权、获准测试额度、参考编辑协议、返回原件与审阅方式尚待提供。取得这些条件后，先做一次授权生成及一次有明确来源的参考编辑，对比字节、远端 ID、实际披露的用量与费用；查单、取消和幂等逐项按供应商实测填写。随后再跑实际服务联调。生产路由/权限迁移、手机真机体验与素材的生产使用权另行验收。上述项目当前均未验证。
