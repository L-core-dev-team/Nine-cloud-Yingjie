## 准入链路

1. 假宿主从隔离存档创建规则输入，保留独立的请求指纹、已完成回执、按序持久化的模拟事件副本、按修订寻址的前后快照。宿主绑定 owner、save、可见性、时间上限及固定 reducer，向研究入口提供进程内只读凭证。出自正文、玩家 action 或 wire 的 `verified` 标志不能得到该凭证。
2. 对已接受回执检查根分支、请求键、`RULES`、`prologue-v1-candidate-20261005`、修订区间和完整批次；逐成员核对原始事件、账号、存档、请求及顺序。缺成员、乱序、无法读取或超越 as-of 均返回 `UNVERIFIED`。拒绝或澄清的真实规则回执则需相同修订前后态及空事件批次。
3. 只接受 `revision-snapshot` 的 R-1/R 状态。验证绑定和摘要，按原顺序逐事件运行固定 reducer，检查差量前置条件、完整 facts、时间、内存策略和最终存档包。用最新存档冒充历史状态会被拒绝，即使地点 ID 恰好相同亦不能代用。
4. 仅接受成功 `move.arrived`，且事件 `from/to`、非空 `locationChange`、事件前后和提交前后的顶层地点均一致、前后不同。子区域需检查 `currentSublocationId`。完整批次验证通过后发布包含稳定事实 ID、规则版本、回执摘要、前后快照和差量摘要的派生事实。相同请求重复查询新增 0；部分验证失败不会发表前半批事实。真实 `move.bypassed` 与同批 `quest.completed` 均经过 reducer，但不会将绕行宣布为“未移动”。[正常世界移动](evidence/YJ-P04-NATIVE-FACT-01/proof-world-location-change.json) · [子区域实例](evidence/YJ-P04-NATIVE-FACT-01/proof-sublocation-change.json) · [绕行和同批任务](evidence/YJ-P04-NATIVE-FACT-01/proof-out_of_scope_supported_event.json)

## 结论边界与回退

本轮仅适用于合成假宿主、固定候选规则版本、原生 root 存档和该地点白名单。真实服务需在同一授权主体下读取已提交回执，并能提供与该历史提交绑定的快照对，或受信检查点、完整事件及独立可核对的目标状态。现有回执接口的外层 revision 和当前存档不能代替这些条件。PG/Chrome 为 ENV_BLOCKED / NOT_RUN；独立人工评审、生产、真实模型和图像均 NOT_RUN。真实账号读取、模型查询、文字和图片调用次数均为 0，费用 USD 0。角色卡仍为 UPSTREAM_AUTHORITY_GAP，I2 仍为 LIVE_BLOCKED_COST_BOUND。

回退只需停用独立研究入口，丢弃本次派生内存账本。两个 main、生产默认、数据库和旧授权均无改动。[复跑与回退说明](../../packages/native-facts/README.md)
