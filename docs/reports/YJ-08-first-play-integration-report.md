方法 `zh-visible-clause/1` 使用有限中文句式、地点词表、人物列表和前一已确认状态。可以组合明确的进出、完整名单、观察位置、时间和灯光。双引号内的转述、受支持的否定、计划、回忆不会改变眼前事实。即使前半段可识别，只要后半段包含不明变化，也会放弃整段画面判断。事件、投影、正文摘要和提取依据在同一事务提交。

三段超出范围的散文均有可解释的人工预期，例如从“门一合，只剩掌柜独自守店”可读出人员减少，本次规则未能提取。标签由本开发会话编写；独立人员的盲标与真实玩家自由文本评测尚未进行，以上计数不能估计泛化准确率。[规则与反例](../../packages/first-play/test/reference.json) · [补充散文](../../packages/first-play/test/prose.json) · [对照断言](../../packages/first-play/test/extract.test.mjs)

本次自动联调特意只将 I0 配入测试预设目录，保留 I1、I2 作为 YJ-05 本地模拟返回。这样一个角色卡面板即可实际经过全部五种选择。权限、版本、摘要、参考资格仍由既有模块核验。

| 已完成文字或运行条件 | 实际选择与显示 |
| --- | --- |
| 东村入店，正文描述三名人物、柜台双窗和日光 | V1 选已审 I0；原件被改一个字节后下载 404，刷新留空，无模拟发送；恢复后再次显示 I0 |
| 普通交谈；随后两位旅人进来 | 普通交谈保持 V1。确认增人后为 V2，无匹配预设、无合法生成资产参考，自动发起一次本地生成，显示 I1 |
| 再次交谈、离店、复访 | 交谈与复访选择同一已审 I1，离店跳过，旧 I0 下载被拒绝 |
| 关闭和重新开启 | 关闭时继续提交正文，发送次数保持不变。开启后重新核对并复用 I1 |
| 傍晚点灯，首次编辑明确失败 | 选择 I1 为参考，失败状态刷新后保持且未重发。下一条已完成文字为引语，五人和灯光仍为 V3；新事件重新评估后编辑成功，显示 I2 |
| 撤销世界书配图授权 | 已显示原件 URL 返回 404，当前面板跳过，下一段正文正常保存。重新授权后才继续考虑候选 |
| 实际离开一人又回来 | V4 四人超出模拟供应商范围，跳过。V5 恢复五人并选择编辑；结果延迟时，同画面下一轮等待原尝试 |
| 切换会话、迟到与未知 | 新会话显示自己的三人画面；迟到资产只写回原会话。另一编辑注入未知结果，随后同画面文字和刷新均未增加发送。全局书替换后，新会话没有配图授权时继续留空 |
