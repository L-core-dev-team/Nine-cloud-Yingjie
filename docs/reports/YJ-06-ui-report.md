# YJ-06 普通角色卡中的映界入口

2026-11-20，本地 Chrome 模拟联调通过。打开九霄已有普通角色卡会话 `/cards/session/<id>`，选择“进入映界”。桌面并排显示图片与文字，窄屏上下排列。图片区显示地点、视觉版本、人数、样例来源和生图开关。原会话继续处理行动、历史、权限与存档。为适配九霄固定版本 `cd25360c7929e10f8b2b0fad342fedd943d4f323`，Vite 插件在构建时挂载到 CardSession；固定锚点变化会中止构建。上游源码与 main 均无提交。

测试通过页面原有“角色卡行动”输入框及“提交行动”按钮完成回合，再从页面的 original URL 读回字节比对。画面以账户、会话、修订和许可序号限定。新视图卸载或切换时中止旧读取，展示服务独立复核访问权。生图开关和模式入口的选择保存在该浏览器标签页的 sessionStorage，按账户及会话分开。关闭生图停止新调度和本地等待；供应商取消能力保持未知。
