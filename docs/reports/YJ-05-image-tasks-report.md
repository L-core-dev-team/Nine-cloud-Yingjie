## 实际链路

九霄普通角色卡提交行动并完成权威文字历史。回环宿主使用既有 Cookie、账户和会话权限调用 YJ-04。固定酒馆正文经显式标注形成 Scene/Visual。通用模块消费 0.1.1 的 Decision，记录逻辑任务、每次尝试和经过 SHA-256 校验的原件。浏览器只能读取其授权会话的当前视图和通过资格检查的原件。真实运行的是认证 HTTP、九霄历史、两个映界 schema、磁盘、React 页面和 Chrome。剧情回复、观察、图片供应商和按既有摘要批准的审阅使用固定样例。

## 边界和后续接入

本地数据库和外部发送之间存在不可原子提交的窗口。sentAt 表示进入可能送达边界，无法确认是否送达时保留原尝试。生产工作进程须在启动和调度时调用 recover，接入可持久共享的私有原件存储，规划备份和孤儿隔离。只有取得获准供应商、认证、测试额度和明确的协议后，才能验证实际生成、参考编辑、时限、查询、取消及幂等。费用、跨网络恰好一次、生产部署均未验证。

YJ-07 可用授权后的地点身份、视觉版本和可见事实匹配有使用权的世界书或预设图。需给出来源、适用条件、版本和未匹配结果。预设图需经过归属、字节和审阅检查才能进入展示。YJ-08 需在批准的宿主挂载中接入实际文字事实提取、画面决策与审阅，再用获准 API 单独重跑九步流程、故障、迟到、关开和撤权。
