## 已实现的回放

- `narrative-highlight/2` 复用既有 completed-history 访问、会话、连续修订、来源键和正文 SHA 核验。候选保留原文、UTF-16 半开区间、角色、对象和理由。事件 ID 在返回的会话 scope 内解释，候选 ID 混入 scope 与来源键。输入的 action 不提供证据。见[入口](../../packages/highlights/v2/replay.mjs)。
- 权益图以资产和权益类型为键，分别记录原权属、承诺、署名、生效、撤销、变更受让方及重述。同名签署人需有唯一的已签文书和身份证据。保管、伪造、未生效及标的错配均不能单独兑现。对「渡船」，前文目标绑定标的，随后紧邻的退出分成、向受益人交付凭证及书面共有结果共同支持安静高潮。没有推断原先独占所有权。用另一组人物、账簿、权益和受益人做过对照。见[权益图](../../packages/highlights/v2/rights.mjs)及[证据实例](evidence/YJ-P04-H2/samples.json)。
- 赴约需要同一会话内的承诺、等待者、可唯一定位的场景及有连续观察支持的到场。未确认的同名地点保留歧义。推断一个叙事瞬间是否成立与现有 S2 能否核验其画面分开处理。见[赴约记忆](../../packages/highlights/v2/meetings.mjs)。
- `highlight-ranker/2` 分开记录目标、结局、持久影响、代价、关系或战局逆转、可验证的伏笔兑现和封顶的铺垫时距。同时返回同线历史峰值差、全局、最近六修订和各线排名。分值未经人类校准。每条边记录首次取得证据的 learnedAt，晚得到的证明可引用较早事件，旧排名和旧图边快照不能被事后改写。
- `highlight-cadence/1` 仅建议。导演复核要求 S2 当前视觉、人物/场所吻合，以及绑定当轮来源的受信规划许可与空闲任务快照。编辑还须校验既有 S2 参考图复核、原始 PNG 和权限。回放没有生产账本读取器，测试的任务与授权快照来自本地假宿主。没有发送入口。见[时机策略](../../packages/highlights/v2/cadence.mjs)。

## 复跑与接续

使用现有锁定依赖和支持权限模型的 Node，从仓库根运行。record.py 写入本分支的合成测量目录；单次 demo 仅向标准输出打印指定前缀。

```powershell
python packages/highlights/v2/record.py
node --permission --allow-fs-read=* packages/highlights/v2/demo.mjs 长卷-晏家宅 12
node --permission --allow-fs-read=* packages/highlights/evaluate.mjs
```

独立接口为 `replayHighlightsV2(ctx)`，必须由授权宿主提供已保存正文、逐修订回执和 replayOnly。回退时直接使用原 [H1 入口](../../packages/highlights/replay.mjs)；默认宿主没有导入 H2。本轮费用为零，I2、L1/L4 许可和两个 main 均无变更。原生 PG/Chrome/自由角色卡联调维持 **ENV_BLOCKED / NOT_RUN**，S3 保留 **BROWSER_NOT_VERIFIED**。手机、实际画质、生产持久化、外部盲评均 **NOT_RUN**。
