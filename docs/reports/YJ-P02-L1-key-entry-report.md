3. 仅在本人决定使用这笔授权时点击“开始唯一一次 Luna 文字测试”。检查通过后也可直接清除并关闭。若页面已启动测试却中断，查看已有脱敏回执和账本，保持停止。

## 信任边界和生命周期

- 服务仅绑定 `127.0.0.1` 随机端口。前端用 256 位随机邀请换取独立内存会话令牌。邀请通过 URL fragment 交付并随即从当前地址移除。所有操作请求检查回环来源、精确 Host、Origin、同源 Fetch Metadata（如浏览器提供）、自定义令牌头和限定请求体；静态页面不能取得邀请或会话。开始操作还校验独立确认头与服务端 READY 状态。
- 密钥仅走同源 POST 正文。服务使用定长内存缓冲区，清除、超时和取用后覆盖所持缓冲区。输入页使用 password 字段，关闭自动填充、缓存和表单提交，禁止外部资源、框架和 Worker。无日志中间件、Cookie、浏览器存储、遥测和第三方页面资源。真实凭据不会进入 argv、环境、子进程、数据库或回执。Node 以未启用跟踪的方式启动。浏览器与 TLS 实现可能产生由运行时回收的短暂内存副本，页面无法防御已被控制的操作系统、浏览器扩展或外部内存转储。
- 主动清除、正常离页和刷新都会销毁会话。断线或浏览器崩溃依靠 90 秒心跳租约兜底。绝对期限为 15 分钟。测试过程中关闭会话会中止发送信号，已经可能送达的请求仍依原账本处理。
