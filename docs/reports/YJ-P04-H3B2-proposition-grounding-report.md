## Gate B · 核验与事实权限

本地提议器只能读取授权的完成历史前缀。外部测试输入限于有大小上限的 JSON 数据。错来源、错会话、越时、缺段、重复或自报权威字段时整批拒绝。核验器独立检查前件、施事与接受方、标的、后果、时态和反证。即使实际签收成立，缺少现实前件也无法确认某项承诺已兑现。待核、直接支持的语句后果、整条命题、独立生效及因果链接分别记录。oracle 提供结构化命题，不能写入事实状态。

新增非财产类事件需完整证据才能在草稿中共同发布事实和因果边。产权仍由原事务核对文书、登记、实质权属与因果依据。转入公账只证明账户收款，共有不证明具体成员份额。检测到非现实叙述边界后，研究入口会隔离没有范围身份的旧账本，再次确认现实事实须有可归属的现实前件与结果。新语义事实不取得导演或发送资格。[实现与复跑入口](../../packages/highlights/h3b2/README.md)
