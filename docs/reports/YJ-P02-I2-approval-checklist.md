# 未来图片试点的逐笔审批与读屏清单

当前状态 **LIVE_BLOCKED_COST_BOUND**。此文档供未来实现受保护的预检界面使用，本轮没有启用页面、凭据输入或任何真实按钮。

| 屏幕项目 | 首张生成 | 后续参考编辑 |
|---|---|---|
| 目的 | 开发自编合成酒馆初次进入 | 限定同一地点，明确新增人物及须保留的人物、结构、时间与光照 |
| 实际外发内容 | 展示来自已保存修订的完整合成提示，并显示只读源修订、正文 SHA、提示 SHA | 展示完整编辑提示、原件预览、精确 SHA、来源 attempt、同一场景和当前有效的已接受审阅编号 |
| 模型与请求 | 展示确认的 Project、准确模型、POST generations、画幅、质量、PNG、n=1 | 独立确认 Project、模型、POST edits 和规格。另行勾选允许该特定原 PNG 仅用于此次参考编辑 |
| 逐笔批准 | 新 approvalId、操作、用途、持有人和会话绑定、授权和到期时间、最多一次 | 新 approvalId，核对首张真实生成原件的接受记录。历史工具图、pending、已拒绝或撤权原件均无默认外发权 |
| 美元读屏 | 展示文字输入、图片输出的有效费率及币种、上界依据、单笔上限、批次总额、累计占用、此次预留和剩余额度 | 同项展示，另列图片输入的可强制计费上界。任一项未知时显示阻塞原因并禁用执行 |
| 用户动作 | 先预览并批准准确的模型、金额、数据及用途。凭据只由可信秘密控件临时接收 | 在同样的受保护界面重新确认本次编辑。编辑许可不能沿用生成许可 |
| 最终执行 | 唯一按钮“执行本次唯一生成”，提交持久占用后最多一次 | 唯一按钮“执行本次唯一参考编辑”，提交独立占用后最多一次 |

只读预检、首次填写凭据、打开或刷新页面均不发送。按阶段展示发送前拒绝、服务端提交、可能送达、已见响应、原件落盘待审、停止；标明本次审计编号。断线、未知、账本不可读或无法确认送达时保留占用，无自动重试、查询或取消。不得记录凭据、原始提示、身份或原图字节到对外回执。

实际返回仍须单独审阅人数、遮挡、衣着与人物位置、柜台/双窗布局、时段及灯光，无法判断的元素逐项记录。第一张获准展示和第二笔获准外发分别确认。供应商最终金额须以其计费证据核对。
