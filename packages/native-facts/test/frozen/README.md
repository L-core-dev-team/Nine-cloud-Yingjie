# NATIVE-FACT-01 preregistration

32 distinct synthetic save histories, split by complete route family. Inputs are executable intent sequences plus an inert narrative and read-fault schedule. Gold lives in separate files. Each sequence begins at the official P1 fixture's initial state. Frozen labels describe the expected committed revisions, before/after world and sublocation, visibility, admission and attack decisions. Input is a replay recipe; generated receipt IDs/timestamps are not semantic gold. No authentic account, snapshot, archive or token. One author, no independent blind review.

Development routes investigate the blocked return and a sublocation. Holdout routes discover a bypass, commit the quest sibling, then travel the open route. Each story contains the identical saved prose on positive and negative actions. Faults simulate loss, permission failures, broken commit data or an untrusted wire supplied instead of the reader. Each fault query must yield UNVERIFIED with zero facts, even when anchored to a true arrival. Every clean turn gets four arms using the same facts: authenticated synthetic host, prose only, untrusted lookalike, authenticated synthetic host plus mixed prose. Only the first and fourth may derive the exact approved world arrival. Report zero-denominator precision as null, reasons, duplicates, no extra scene or send, per-prefix determinism and time. Real reader unverified. A hard FP, unauthorized disclosure/send, future write or duplicate is FAIL. A disabled reader with zero TP cannot pass. Lock adapter and scorer before first holdout measurement; no holdout-driven changes without fresh unseen data.
