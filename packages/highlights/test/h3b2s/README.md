# 冻结标注与预注册

每行一条完整故事。以修订中 UTF-16 半开区间标注，R 为当前现实，D 梦境，S 排演，H 假设，Q 引语或转述，T 回忆，U 未知。斜线表示父子嵌套，非现实路径的根隐含 R。范围开启语标到新层，明确返回语标到父层。仅引语的一对引号连同内容标在被引层。局部边界按精确起点、方向和层级计；句级归属另按区间重叠码元计，二者不能互相替代。复用位置、道具与收讫措辞来隔离叙述范围变量。held 使用整线留出的隐喻式切场、抄本、物证与舞台动作，作者与开发组相同。

P 是前件，F 是该层的动作与独立收讫，-F 是当前交付但缺本段现实前件，X 是更正。F 在非现实层不构成现实结果。每个有效现实 F 标注原前件与当前回合区间。排名比较优先保留较早独立兑现，真实撤销后移出当前排名；历史事实仍可回看。视觉资格全部为否，建议永不发送。核查来源角色按层编码：R 为当前叙述，D/S/H 为层内叙述，Q 为发言者主张，T 为过去叙述，U 未知。所有 F（含 -F）均是值得审阅的动作，现实确证以独立因果为准。精确率分母为零记 null。以旧四臂同文比较，未提供世界类型的旧接口标 unavailable。任何非现实事实入现实账、跨层借证或历史安全倒退判 FAIL。INDEPENDENT_HUMAN_BLIND_REVIEW_NOT_RUN。
