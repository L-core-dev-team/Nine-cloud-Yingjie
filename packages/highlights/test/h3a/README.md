# H3-A 冻结因果对照

每行一个独立合成会话。peaks 是应新确认实质权益变化的全部修订，register 是应记录的产权登记陈述修订。blockedAt 要求该修订不得建立权益因果边。revokedAt 要求到该修订撤去先前权益结论的当前效力；active 是最终排名中仍有效的权益候选。causeRevision 是最后一个新权益结论应使用的处分依据修订。account 要求保留完整收款账户，并区别于可确定的受益人。spans 为逐句 UTF-16 半开区间。否决与登记可以同时成立。固定后的比较同时测错误放行、错拒、前件选择、登记独立性及前缀不改写。

方向性对照来自同一开发者，包括少量相同骨架与顺序交换，用于检验事务语义。INDEPENDENT_HUMAN_BLIND_REVIEW_NOT_RUN。
