# 首段游玩本地联调

在原九霄普通角色卡页面点击“进入映界”。本地首段游玩宿主自动选择图片来源。运行 `node packages/ui-shell/demo.mjs` 可打开可交互演示；固定上游、本地角色卡 PostgreSQL、Chrome 和环境变量准备见 [05 运行说明](../image-tasks/README.md)。演示的文字供应商按回合输出[示例正文](story.mjs)，可以每轮提交相同的行动。画面入口仅读取已有鉴权历史中的 completed 正文。

## YJ-09 复访与重建

交互演示默认选用 [zh-visible-clause/2](continuity.mjs)。它依据受信正文解析明确的离场、全量名单、时段与灯光，并按村名和已登记别名复访。位置已知但人物变化含糊时，面板可继续文字行动；地点的最后确认名单保留，当前图片等待完整调查。原 /1 提取器及 08 回归仍可使用各自的库。

[replayHistory 和 compareReplay](replay.mjs) 接受独立的映界 PG 投影库和绑定当前鉴权的九霄 HTTP 读取器。先在独立库运行 scene-state、image-tasks、first-play 的原有 schema。重放仅从 completed 历史读取并写入状态/审计，按 scope 对比原始事件键、正文摘要和视觉版本。重放标记禁止普通消费者追加或派发图片；既有会话接入空图片账本时可读取合格预设，其他发送留待原账本对账。版本切换无需修改权威正文。回退使用旧宿主与其原库。

[实测报告、复跑命令与限制](../../docs/reports/YJ-09-revisit-continuity-report.md)

## YJ-08 提取及对照

[extractSaved](extract.mjs) 接收已校验的 card-history、trim 后的正文和该事务内的上一状态。它按引号边界分句，再识别有限的中文叙述结构。当前地点词表涵盖东村及西村的青石酒馆；识别明确的名单、特定衣色客人进出、正门/后门视角、结构、日间/傍晚和灯光。引语、受支持的计划、否定和回忆不会写入当前场景。未识别的分句会令该段整体未就绪；在可见事实重新完整陈述后可重新建立当前视图。单凭地点重名或再次提名不会填补不明事实。

YJ-04 的同一事务保存剧情事件、已接受观察、状态/检查点及提取审计。审计记录方法版本和各分句在 trim 后正文中的 UTF-16 偏移、长度、规则名。原文由九霄保管，已有事件保存原文及归一化摘要。更换提取方法或从旧固定标注切换时，应在新的独立投影库中重放历史，缺少匹配版本的前序审计时拒绝接续。旧样例提取器仍可返回原有观察数组。

[规则对照集](test/reference.json) 与[补充散文对照集](test/prose.json) 是开发会话单独手写的预期观察。运行时不读取这些标签。前者校验操作和放弃判断的边界，后者将语义一致、无法判定、提取错误分别计数。两组均为合成语料；独立人工盲评和真实游玩语料评测待做。

## 画面选择与存储

[chooseFrame](planner.mjs) 依次检查开关、场景就绪、07 的预设资格和已登记事件。允许继续本地任务的无匹配原因包括没有世界书、该地点没有预设和视觉不符；越权、审阅不合格、损坏和歧义会隐藏画面。已登记任务复用同一逻辑请求。新的就绪事件按 0.1.1 核对本会话、本地点、真实原件和审阅：同画面可复用，变化后从合格的历史资产中选编辑参考，保留仍然可见的人物与结构。遇到同一视觉的待返回或未知尝试，会等待或保留未知。无参考时仅在本地模拟供应商已支持该画面时生成，否则跳过。预设句柄独立于任务、尝试和生成资产。

[自动视图](view.mjs) 将开关、修订、许可序号、选择、原因与候选句柄写入独立 [schema](schema.sql)，同一条件的轮询去重。YJ-05 持有发送、回执和恢复状态，原件下载重新检查当前会话、画面和使用权。关图沿用本地演示的隐藏策略。旧 05/06 图片任务与 07 预设模式继续作为独立回归入口。

本地自动宿主只装配 mock。演示目录故意只开放 I0 作为预设，I1 和 I2 由模拟任务返回已有 YJ-02 字节，从而能在同一页面观察预设、复用、编辑、生成和跳过。所有图片均为获准样例。回退时停用自动宿主，切回 07 的既有挂载并保留各自的数据库；无需更改上游九霄表或权威文字。
